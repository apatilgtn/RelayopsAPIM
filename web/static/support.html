Help yourself first

  • Developer hub: browse APIs, try calls, and manage your keys at /portal.
  • Request IDs: every gateway response carries X-Request-ID; administrators can look it up in Request logs to see exactly why a call was allowed or refused.
  • Common refusals: 401 means a missing or invalid API key; 403 means the key has no active subscription to that API; 429 means a rate limit or quota was reached (for rate limits, the Retry-After header says how many seconds to wait).

Report a security issue

Email apatil@relayops.cloud with the subject "Security report". Please give us a reasonable chance to fix the issue before disclosing it publicly, and don't access other people's data or disrupt the Service while testing. We will acknowledge reports within 2 business days.
