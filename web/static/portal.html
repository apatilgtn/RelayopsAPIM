Quickstart

Getting started

A complete 4-step onboarding guide to integrating with RelayOps APIs.

01

Find your API & Review Contract

Browse the catalog and open the API reference. Check authentication requirements, endpoints, parameters, and download the full OpenAPI 3.0 specification.

Explore APIs
02

Register an application

Navigate to Get access. Choose a plan published by the API owner, register your app, and copy your private API key to your secret vault. Plan prices are the API owner’s catalog, not RelayOps subscription fees.

Register an application
03

Send Authenticated Requests

Include your credentials in each request: X-API-Key: <key> for API key authentication, or Authorization: Bearer <token> for JWT/OIDC APIs.

Open the workbench
04

Production Rate Limiting & Error Handling

Inspect gateway response headers: X-RateLimit-Limit, X-RateLimit-Remaining, and Retry-After. If throttled (HTTP 429), pause for the specified retry period using exponential backoff.

View personal logs & usage
GATEWAY HEADERS

Standard Response Protocol

X-Request-ID Unique telemetry ID for end-to-end tracing.

X-RateLimit-Remaining Requests left in current window.

Retry-After Seconds to pause when throttled (HTTP 429).

ERROR REFERENCE

401 Unauthorized Missing or invalid API key / expired token.

403 Forbidden Subscription pending approval or role restricted.

429 Too Many Requests Exceeded minute rate limit or daily quota.

502 / 504 Gateway Error Upstream backend is unreachable or timed out.
